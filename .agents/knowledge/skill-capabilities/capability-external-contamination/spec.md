# Skill Content Relevance

## Requirements

- Active Profile Tailors skills use examples, package names, commands, paths, and bounded contexts
  that exist in this repository or are explicitly labeled as generic reference material.
- Do not copy another product's identifiers, package names, or application routes into project
  examples.
- When a skill uses an external framework example, name its scope so an agent does not mistake it
  for repository structure or an implemented dependency.
- Review content manually when editing the affected skill and directly linked references. No
  contamination scanner or skill CI gate is required; see ADR-0026.

Archived remediation changes retain their original examples and terminology as historical records.
