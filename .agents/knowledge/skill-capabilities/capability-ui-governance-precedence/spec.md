# UI Guidance Precedence

## Authority order

1. `.agents/DESIGN.md` and the applicable surface `PRODUCT.md` own product visual tokens, brand
   commitments, and surface constraints.
2. `impeccable` owns the design process and quality review while preserving product truth and the
   established visual system.
3. `nothing-design` supplies Profile Tailors' visual language and applies automatically to design
   work in this repository.
4. `frontend-design` is generic inspiration for choices that the project system and specialized
   skills leave open.

## Requirements

- A skill or external source does not override `.agents/DESIGN.md` or the applicable `PRODUCT.md`.
- `nothing-design` does not require the user to reselect a design language for Profile Tailors.
- Generic recommendations that conflict with project fonts, palette, components, modes, or product
  constraints are ignored.
- The precedence is maintained as ordinary design documentation, without a skill-format validator
  or dedicated CI gate.
