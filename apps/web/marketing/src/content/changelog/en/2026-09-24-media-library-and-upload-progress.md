## Dedicated workspace Media Library

Store images and video assets inside your workspace so drafts and scheduled posts can reuse approved visuals without re-uploading files on every post.

- Browse uploaded assets in a scannable monochrome grid with file metadata.
- Attach existing library assets directly from the post composer.

## Non-blocking upload progress toast

Longer uploads no longer block your planning workflow. A persistent bottom-corner progress indicator tracks active uploads while you navigate between Calendar, Ideas, and Settings.

- Clear per-file progress percentages and specific error messages if an upload fails.
- Keyboard-accessible controls with live-region announcements for assistive technologies.
