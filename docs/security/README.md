# Security Documentation

## Overview

This directory contains security-related documentation and guidelines for Profile Tailors. It covers
security scanning infrastructure, vulnerability management, and links to the project's security
policy.

## Changes

See individual documents for their change history and status updates.

## Usage

Review the scanning stack documentation to understand the layered security scanning approach used in
this project. For reporting security vulnerabilities, refer to the security policy in the repository
root.

## Troubleshooting

If you encounter issues with security scans or need to report a vulnerability:

- For scan failures in CI, check the [Scanning Stack](./scanning-stack.md) documentation for
  configuration details
- For security concerns or vulnerabilities, follow the process outlined
  in [SECURITY.md](../../SECURITY.md)
