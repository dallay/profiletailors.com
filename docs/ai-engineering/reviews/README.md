# Review Evidence

## Overview

Evidence backing AI-assisted engineering reviews. Parent workflow lives in [AI-Assisted Engineering](../README.md).

## Usage

- [Review Evidence](./REVIEW-EVIDENCE.md) — stored review inputs and outputs

## Troubleshooting

- Evidence is append-only context; new reviews get new entries instead of rewriting past ones.
- If evidence conflicts with current specs, trust current `.agents/sdd/specs/` plus verification reports.
