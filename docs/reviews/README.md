# Reviews

## Overview

Independent quality reviews with findings and remediation scope. Reviews diagnose; fixes land in code changes, not in review edits.

## Usage

- [Tenancy 4R Review](./4r-review-tenancy-remediation.md) — quality and resilience review for tenancy remediation

## Troubleshooting

- If a review is stale, open a new review instead of rewriting history.
- Link remediation PRs back to the review section they close.
