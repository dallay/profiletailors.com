# Lighthouse Baseline

## Overview

Tracked performance baseline for the marketing surface.

## Usage

- [baseline.json](./baseline.json) — stored Lighthouse scores and metrics
- Compare new runs against this file before claiming a performance change.

## Troubleshooting

- If scores swing without code changes, check network throttling and runner hardware first.
- Keep this file in version control; do not store baselines only in CI artifacts.
