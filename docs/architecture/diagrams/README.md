# Login Diagrams

## Overview

Login flow visuals. Text truth lives in [Login Flow](../login-flow.md); these files render it.

## Usage

- [Login Sequence](./login-sequence.html) — current login end to end
- [Refresh and Hydrate](./login-refresh.html) — rotation and hydrate
- [Login Decisions](./login-decisiones.html) — decision flowchart

## Troubleshooting

- If a diagram disagrees with `login-flow.md` or code, trust code plus tests, then update the diagram source.
- Open the HTML files in a browser; they are static exports, not live views.
