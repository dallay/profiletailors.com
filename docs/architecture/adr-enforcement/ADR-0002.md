# Enforcement plan for ADR-0002 (Hexagonal Architecture)

## Rules derived from the ADR

| Rule                  | Mandatory | Current enforcement      | Gap   |
|-----------------------|-----------|--------------------------|-------|
| Domain Isolation      | Yes       | HexagonalArchTest.kt     | None. |
| Application Isolation | Yes       | HexagonalArchTest.kt     | None. |
| Custom @Service Usage | Yes       | ComponentScanArchTest.kt | None. |

## Proposed automated checks

### Spring Stereotype Guard

- **Mechanism**: ArchUnit.
- **Files**: `ComponentScanArchTest.kt`.
- **Expected failure**: "Application layer classes must use
  @com.profiletailors.common.domain.Service."
- **Priority**: High (Already implemented).

### Observability Vendor Guard

- **Mechanism**: ArchUnit rules shared through the `shared:common` test fixtures.
- **Files**: `server/smp/src/test/kotlin/com/profiletailors/smp/HexagonalArchTest.kt` and the
  architecture tests in `shared/storage`, `shared/presentation`, and `shared/shield/ratelimit`.
- **Rules**: `domain` and `application` do not depend on SLF4J, Logback, Log4j, Micrometer,
  OpenTelemetry, or Jackson; `domain` does not depend on `OperationalEventSink`.
- **Status**: Implemented. The reusable rule is
  `com.profiletailors.architecture.ObservabilityArchitectureRules`; module-specific layer rules
  remain unchanged.
