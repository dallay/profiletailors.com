# Enforcement plan for ADR-0001 (Modular Monolith)

## Rules derived from the ADR

| Rule                                        | Mandatory | Current enforcement                      | Gap                                        |
|---------------------------------------------|-----------|------------------------------------------|--------------------------------------------|
| Spring Modulith Verification                | Yes       | ModularityVerificationTest.kt (Disabled) | Test must be enabled and passing.          |
| Forbidden Cross-Context Infrastructure deps | Yes       | None                                     | Automated check for cross-context imports. |

## Proposed automated checks

### Re-enable Modulith Verification

- **Mechanism**: JUnit 5 + Spring Modulith.
- **Affected build**: `:server:smp`.
- **Files**: `ModularityVerificationTest.kt`.
- **Priority**: High.

### Custom Konsist/ArchUnit Context Guard

- **Mechanism**: ArchUnit.
- **Expected failure**: "Context A must not depend on context B infrastructure."
- **Priority**: Medium.
