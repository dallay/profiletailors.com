# ADR Discovery

## Overview

Working area for decisions that are not ADRs yet. Nothing here is normative; accepted decisions live in [ADR Index](../adr/README.md).

## Usage

- [Candidate Decisions](./candidate-decisions.md) — catalog under review
- [Documentation Drift](./documentation-drift.md) — drift findings
- [Synchronization Plan](./documentation-synchronization-plan.md) — doc sync sequence
- [Evidence Ledger](./evidence-ledger.md) — evidence backing the candidates

## Troubleshooting

- Do not cite this folder as an architecture decision. Promote the candidate to `../adr/NNNN-*.md` first.
- If a candidate conflicts with an accepted ADR, the accepted ADR wins until superseded.
